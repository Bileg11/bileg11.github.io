LFS Shanghai — `reviews` цуглуулгын Firestore дүрэм
═══════════════════════════════════════════════════════════════════════

Хаана тавих вэ:
  Firebase Console → lfs-shanghai → Build → Firestore Database
  → Rules таб → доорх `match /reviews/{id}` блокийг НЭМЭЭД → Publish

⚠️ Бусад цуглуулгын (bookings, finances, users, planners) дүрмийг
   БҮҮ УСТГА. Зөвхөн доорх блокийг нэмнэ.

───────────────────────────────────────────────────────────────────────

    // ── Үйлчлүүлэгчийн үнэлгээ ──
    // Хэн ч илгээж чадна, гэхдээ зөвхөн зөв бүтэцтэй, status='pending'.
    // Уншиж, зөвшөөрч, устгахыг зөвхөн админ хийнэ.
    match /reviews/{id} {

      // Илгээх — нэвтрээгүй хэрэглэгч ч болно, гэхдээ хатуу шалгуултай
      allow create: if
           request.resource.data.keys().hasOnly(
             ['rating','pkg','name','text','consent','status','source','createdAt','ua'])
        && request.resource.data.rating is int
        && request.resource.data.rating >= 1
        && request.resource.data.rating <= 5
        && request.resource.data.pkg in ['full','basic','travel','other']
        && request.resource.data.name is string
        && request.resource.data.name.size() >= 2
        && request.resource.data.name.size() <= 40
        && request.resource.data.text is string
        && request.resource.data.text.size() >= 15
        && request.resource.data.text.size() <= 600
        && request.resource.data.consent == true
        && request.resource.data.status == 'pending'   // өөрөө зөвшөөрөгдөх боломжгүй
        && request.resource.data.source == 'form';

      // Унших / зөвшөөрөх / устгах — зөвхөн админ
      allow read, update, delete: if
        request.auth != null && request.auth.token.email == 'amarsaikhanbileg@gmail.com';
    }

───────────────────────────────────────────────────────────────────────

Яагаад ийм хатуу вэ:

 · `hasOnly([...])` — гаднаас дурын талбар нэмж, өгөгдлийн санг
   хогоор дүүргэхээс сэргийлнэ
 · `status == 'pending'` — хэн ч өөрийгөө шууд "зөвшөөрөгдсөн" болгож
   чадахгүй. Чи admin дээрээс л зөвшөөрнө.
 · `size()` хязгаар — спам, маш урт текстээс хамгаална
 · `allow read` нээлттэй БИШ — учир нь модерацлагдаагүй үнэлгээ
   олон нийтэд харагдах ёсгүй. Сайт дээр харагдах үнэлгээ нь
   `js/reviews.js`-ээс гардаг, Firestore-оос биш.

И-мэйл нь admin/index.html доторх ADMIN_EMAILS-тэй тааруулсан.
